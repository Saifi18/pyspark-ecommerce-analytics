# PySpark E-Commerce Analytics

## Project Overview

A production-style PySpark data engineering project that processes e-commerce customer, product, order, and transaction data to build analytics-ready datasets.

## Business Problem

The project simulates an e-commerce organization that needs reliable customer, product, and transaction analytics from raw operational data.

## Objectives

- Ingest and validate raw data using PySpark
- Apply data quality and cleaning rules
- Build analytics-ready datasets
- Perform customer and product analysis
- Apply joins, aggregations, and window functions
- Analyze Spark execution and optimize transformations
- Document the pipeline and engineering decisions

## Technology Stack

- Python
- PySpark
- Parquet
- Google Colab
- Git / GitHub
